# Project Manager

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Productivity Tool](https://img.shields.io/badge/productivity-tool-green.svg)]()

A powerful project management CLI with task tracking, time logging, and detailed reports.

## ✨ Features

- **Task Management** - Create, update, complete, delete tasks
- **Project Organization** - Multiple projects, archive, delete
- **Time Tracking** - Start/stop timer per task, view time reports
- **Priority Levels** - Low, medium, high, urgent
- **Tags & Categories** - Organize with flexible tags
- **Due Dates** - Track deadlines
- **Statistics & Reports** - Weekly and monthly productivity reports
- **Rich UI** - Beautiful colored terminal output
- **SQLite Database** - Local persistence, no server needed

## 📦 Installation

```bash
git clone https://github.com/Master-626/project-manager.git
cd project-manager
pip install .
```

## 🚀 Quick Start

```bash
# Add a task
project-manager add "Finish documentation" -p high

# List tasks
project-manager list

# Complete a task
project-manager done 1
```
